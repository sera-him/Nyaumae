📖 游戏规则

1. 系统给出 N 个数字（N 由难度决定：3~42）

2. 目标值已显示，你需要用这 N 个数字构造表达式使结果接近目标

3. 可用运算符：+ - * / ( ) √ sqrt(x) ! ^

4. 点击上方蓝色按钮可快速插入符号（支持复制粘贴）

5. 必须恰好使用给定的 N 个数字各一次

6. 阶乘仅对非负整数有效

7. 根号内不能为负数，可用 √x 或 sqrt(x)

8. 支持无理数答案（如 √2、√3+1 等），按浮点精度评分

9. 数值范围：指数位最大支持 10^10000
