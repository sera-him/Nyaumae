# 行为好坏的外部判定准则（三正向要件 / 三负向触发，不作践行准则）

- 日期：2026-11-04
- 状态：已接线（2026-11-04 核对确认已接入前端与中英检索/词频；canon 评审待办）

- 备注：正向三要件（统治者真实认同且亲身参与 + 相关群体多数完全自愿参与 + 结果正向无害）；负向三触发（统治者避之不及 / 仅少数人能为 / 非完全自愿）；并限定用途——只能从外部视角判断世界好坏、不能当践行准则以压缩主观操作空间。归属与是否并入既有原则，启动时判定。

## 原话（逐字保留）

任何一个行为，若满足「统治者真实认同且亲身参与 + 相关群体多数人完全自愿参与 + 行为结果正向无害」，则它是好的；反之，若满足「统治者避之不及 或 仅少数人能为 或 非完全自愿」，则它有可能是坏的。不能被当做践行准则，不然的话可操作空间可就大了。可以只能用来从外部视角来判断一个世界好不好，这样就可以避免引入一些主观的自己的价值观。
