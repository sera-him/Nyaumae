## 原话（逐字保留）

好，把整条 Cayley–Dickson 祖传的"得失总账"一次结清。从上往下读，左边是你买到的东西，右边是你亏掉的东西：

## 总账

| 扩张 | 得到 | 失去 |
|---|---|---|
| **ℕ → ℤ** | **减法**封闭（每个数有加法逆元，出现负数） | **良序性**（ℕ 每个子集都有最小元，ℤ 没了） |
| **ℤ → ℚ** | **除法**封闭（非零元全可逆，成为域） | **离散性 / pre & nex**（变成稠密：任何两数之间还有别的数） |
| **ℚ → ℝ** | **极限**封闭（完备性：$\sqrt2$、$\pi$、柯西列都收敛） | **可数性**（康托对角线；ℝ 的势是 $2^{\aleph_0}$） |
| **ℝ → ℂ** | **解方程**封闭（代数基本定理：开任意次方、任意多项式有根） | **可序性**（就是只卖 1.99 元那位，$i^2=-1$ 没法比大小） |
| **ℂ → ℍ** | 三维旋转的优雅表示；最后一个**结合**的可除代数（Frobenius） | **交换性**（$ij = -ji$） |
| **ℍ → 𝕆** | 几乎没有新东西——只剩"两元素生成结合子代数"（Artin 定理）这块遮羞布 | **结合性**（$[e_1,e_2,e_4]=2e_7\neq0$） |
| **𝕆 → 𝕊**（16元） | 维数 ×2，仅此而已 | **交错性**、**无零因子**、**范数乘性**（$(e_3+e_{10})(e_6-e_{15})=0$ 首次登场） |
| **𝕊 → 32元** | 维数 ×2 | 无著名性质可丢（幂结合、柔性还在） |
| **32 → 64 → … → $2^n$** | 维数 ×2 | 同上，只剩越来越稀疏的零因子越来越多 |

## 幸存者名单（一路活到最后的性质）

- **幂结合律** $a^m a^n = a^{m+n}$——靠"每个元素满足实系数二次方程"白送，永不丢；
- **柔性律** $(ab)a = a(ba)$——换位子被实部吸收，永不丢；
- **对合 / 二次性**：$x + \bar{x} \in \mathbb{R}$，$x\bar{x} = |x|^2$——CD 构造自带，永不丢；
- **彩蛋**：每一级每个非零元素都还有逆元 $x^{-1} = \bar{x}/|x|^2$——注意这是"得与失并存"：16 元之后**人人可逆**，但**零因子遍地**，在非结合世界里这两件事不矛盾。

## 永不复得名单（丢了就永远丢了）

- 可序性：2 元丢，之后 $\mathbb{C} \subset$ 一切，永远回不来；
- 可数性：实数丢，之后全包含 $\mathbb{R}$，永远不可数；
- 交换性：4 元丢；结合性：8 元丢；交错性：16 元丢。

## 三句话总结

1. **前四步是好买卖**：减法、除法、极限、解方程——每步用一种结构性质换一类新运算的封闭，全部换完正好停在复数。
2. **四元数起是纯亏损**：没有新运算可买，只剩维数在涨，性质一路贬值。
3. **最后两个守阵老兵**是幂结合律和柔性律——因为加倍只破坏"三个以上元素"之间的结合，而它们只管一个元素的幂、和两个元素的三明治。
