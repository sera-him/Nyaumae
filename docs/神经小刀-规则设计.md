# 《神经小刀 · Ny刀》规则设计文档

> 状态：规则草案 v1（仅规则，未实现）
> 定位：为 Neural Connection 世界观设计的一款「同时出招 · 能量博弈」游戏
> 原型：中文校园游戏「波波攒 / 攒气发波 / 拍手游戏」（上海话「饼·汤·轰」）
> 适配：拟接入 `/playground/games`，风格沿用现有 Playground 的 aurora 实验场语言

---

## 0. 一句话

两名意识体在同一个「神经周期」内**同时出招**：把神经能**攒**起来、用它**挥刀**，
或把神经能摊开成**刃幕**。只有挥刀能直接结束对手，防御只保证不死，刀锋只在
「对方正在积能」的那一瞬间才真正致命。

## 1. 世界观定位：这是什么

### 1.1 场景

《神经小刀》是**科照真学院机试（非笔试）**的公开对抗项目，也是《心界》里
`MuChengYiBai` 活动期间同步上线的**神经共振小游戏**。两条线共用同一套规则内核：

| 皮 | 场景 | 观众 | 赌注 |
|---|---|---|---|
| **机试皮**（主线） | 冯·诺伊曼班的走廊 / 机试考场 | 同届考生、监考 | 谁能拿到最后一个机试名额 |
| **心界皮**（副线） | 《心界》VR 神经回路副本 | 围观玩家 | 段位与「零」的一句评价 |

选这个场景的理由：世界观里 **QET 机试的核心机制就是"预测"**——
> 「做题时先猜自己能得多少分（预测）；如果实际得分 ≥ 预测 → 拿预测分；
> 如果实际 < 预测 → 拿 0 分。」

"同时出招 + 能量博弈"本质上就是一个**双向预测游戏**：你必须猜对方这回合
在攒、在防、还是已经攒够挥刀。机试的预测哲学和这个游戏的内核完全同构。

### 1.2 术语映射表

全部取自现有世界观数据（`worldSettings.ts` / `dictionary.ts` / `organizations.ts`）：

| 通用博弈术语 | 本作术语 | 世界观出处 |
|---|---|---|
| 能量 | **神经能**（*neural charge*） | 假说：「神经密度越高，意识值越大，且为 S 型曲线」 |
| 积能 | **积能 / 蓄能**（攒） | 神经密度积累 |

| 必杀大招 | **共振斩**（能阶 ≥ 5 时解锁） | 「神经共振」 |

## 2. 核心机制

### 2.1 神经能（能量）

- 每名角色拥有 `神经能`，取值 **0 ~ 6**（`能阶`）。
- 开局双方均为 **0** 能。
- 神经能是**公开信息**，双方全程可见。

### 2.2 一个回合

```
第 N 回合：
  1. 双方各自秘密选定一个招式（不显示给对方）
  2. 同频倒数：3 → 2 → 1，同一瞬间亮出
  3. 结算（按第 4 章表格）
  4. 状态更新（能量增减、存活、连续统计）
  5. 若无人被淘汰 → 进入第 N+1 回合
```

**为什么要有"同频倒数"**：原版游戏靠拍手保持节奏，抢拍/错拍判负。
本作把这条搬过来并升级成**风险维度**——`神经频率对不上`（抢拍）在本作里
不是输给对方，而是直接触发自己的 **Meltdown**。这样"节奏"本身就是代价。

### 2.3 三类动作（全部招式的分类）

所有招式都属于且仅属于三类。**记住这三类就能玩，记住招式只是变强。**

| 类 | 名称 | 作用 | 典型 |
|---|---|---|---|
| **A 类 · 蓄能** | 积能系 | 增加能阶，本回合不主动取胜 | 积能、深呼吸、屏息、涌流 |
| **B 类 · 挥刀** | 出刃系 | 消耗能阶攻击，本回合可能直接结束对局 | 轻斩、重斩、共振斩、贯穿 |
| **C 类 · 守** | 守御系 | 削减来袭伤害，本回合不主动取胜 | 刃幕、侧滑、反射、假动作 |

> **三类的克制骨架（原型核心，改写为本作表述）**
> ```
> 出刃  >  蓄能   （挥刀打中正在积能的人 → 直接结束）
> 守御  >  出刃   （刃幕摊开能挡刀，但挡不住共振斩）
> 蓄能  >  守御   （对面越守，你攒得越快；守方永远赢不了）
> ```
> **只有出刃能赢。** 守御保证不输但不赢；蓄能为下一刀铺路。
> 整个游戏的全部策略，都来自"用哪一刀、在什么时机、对谁"。

## 3. 招式表

### 3.1 A 类 · 积能（蓄能系）

| 招式 | 能阶 | 效果 | 备注 |
|---|---|---|---|
| **积能** | +1 | 神经能 +1 | 唯一的纯积能动作，第 1 回合唯一可用招 |
| **深呼吸** | +1 | 神经能 +1；本回合受到的挥刀威力 **−1** | 慢慢吸气的人，刀更难砍实 |
| **涌流** | 0（需 ≥3） | 神经能清零，改为 **+3** | 攒够就梭。注意"清零"是风险也是节奏 |
| **双生** | 0（需 ≥4） | 能阶不变，本回合结束后 **下回合积能 +2** | 一次投资换两次，适合铺 5 能大招 |

> **设计意图**：`涌流` 和 `双生` 是原型里没有的。
> 原版的"攒"只有一种（+1），导致积能的价值曲线太平；
> 这两条把"积能"内部也做成了有取舍的小博弈——
> 要不要梭上去换爆发，还是稳着攒。

### 3.2 B 类 · 出刃（挥刀系）

出刃统一规则：**消耗全部神经能，威力 = 消耗量**，挥出后能阶归零
（`双生` 除外，它不在这里结算）。

| 招式 | 需能阶 | 威力 | 效果 |
|---|---|---|---|
| **轻斩** | ≥1 | 消耗值 | 基准一刀 |
| **重斩** | ≥2 | 消耗值 +1 | 少一刀，多一分威力 |
| **贯穿** | ≥3 | 消耗值 +1 | **无视守御系的"格挡"**，但被"反射"克制 |
| **共振斩** | ≥5 | 消耗值 | 见 §4.4 清场规则 |
| **借势** | ≥1 | 消耗值 | 命中蓄能中的对手时，**不结束对局**，改为夺取对手 1 点能阶 |

> **设计意图**：
> - `贯穿` 对应原型的"枪/竖切"（破神防/破神反），是**防反特化的刀**。
> - `借势` 是本作的"偷气"变体，把"杀人"改成"抢资源"，用于节奏控制。
>   它刻意**不结束对局**——避免了原版"一击必杀"的过度紧张，
>   也给玩家一个"稳健选项"，让高手局不至于三回合结束。

### 3.3 C 类 · 守御（守御系）

| 招式 | 需能阶 | 防御力 | 效果 |
|---|---|---|---|
| **刃幕** | 0 | **2** | 摊开神经能成膜。**免费**，但只有 2 级 |
| **侧滑** | ≥1 | 3 | 消耗 1，防御 3 |
| **反射** | ≥2 | 4 | 消耗 2，防御 4，并**反弹等量威力** |
| **深潜** | ≥3 | 6 | 消耗 3，防御 6，**不反弹**；但本回合完全不积能 |
| **假动作** | 0 | 0 | **骗招**。对方若出刃攻击你，你抢先命中（见 §4.5） |

> **设计意图**：
> - `刃幕` 只有 2 级防御是**故意的地板设计**。原型的最大设计缺陷是
>   "无限防导致平局"，社区靠各种村规修补（防强上限、限定连续防御、
>   5 能量清场）。本作**从根上解决**：免费防御硬编码为弱防，
>   想要强防必须**花能量**——而能量正是你想留给挥刀的。
> - `假动作` 把原型的"抢拍判负"反用成**主动博弈**：
>   猜错不亏（只是本回合空过），猜对直接赢。
>   这是本作最像"小刀"的一招——骗对手出刀。

### 3.4 「能阶」= 招式强度天花板

- 能阶上限 **6**。
- 能阶 ≥5 时解锁**共振斩**（清场），≥3 解锁贯穿/涌流，≥2 解锁反射/重斩，≥1 解锁侧滑/轻斩。
- 一句话记忆：**能阶越高，你的招式表越宽，但挥刀后归零的代价也越大。**

## 4. 结算规则

设本回合双方招式为 `我的 A` / `对方 B`。

### 4.1 优先级

结算按固定优先级依次判定，命中即停：

```
1. 假动作对位     → 命中者直接赢
2. 挥刀 vs 守御   → 比防御力
3. 挥刀 vs 挥刀   → 比威力
4. 挥刀 vs 蓄能   → 挥刀方直接赢
5. 守御 vs 守御   → 无事发生
6. 守御 vs 蓄能   → 守御方无事，蓄能方正常积能
7. 蓄能 vs 蓄能   → 双方正常积能
```

### 4.2 挥刀 vs 守御

```
我的威力 W  对  对方的防御力 D
  W  >  D  →  对方被淘汰，我获胜
  W  ≤  D  →  攻击被完全吸收，双方无损
              （我白挥一刀，能阶已清零 → 大亏）
  特例：贯穿 无视 格挡类防御，但仍被 反射 / 深潜 完整挡下
  特例：共振斩 无法被任何守御挡下（见 §4.4）
```

### 4.3 挥刀 vs 挥刀

```
我的威力 W₁  对  对方威力 W₂
  W₁  >  W₂  →  对方被淘汰
  W₁  <  W₂  →  我被淘汰
  W₁  =  W₂  →  互相抵消，双方无损（这就是原版"同威力平手"）
```

### 4.4 共振斩 · 清场（能阶 ≥ 5）

原型社区最重要的"村规"，直接解决无限防：

> **任意一方打出共振斩（能阶 ≥ 5）时：**
> 场上所有**没有同时打出共振斩**的意识体，**立即被淘汰**。
> 两位同时打出共振斩的，按 §4.3 比威力。

这条规则一举三得：
- **破解龟缩**：一直守御的人会被清场直接扫掉。
- **制造质变拐点**：能阶 4 → 5 是全局的转折点，决胜回合必然短促刺激
  （对应原型"5 能量大招"带来的期望值质变）。
- **引入信息博弈**：谁能先攒到 5、谁敢在对方快满时先手，
  变成全局最关键的攻防。

### 4.5 假动作（骗招）

```
我出【假动作】，对方出【任一出刃类招式】：
  → 我抢先命中，**我获胜**，对方被淘汰

我出【假动作】，对方出【蓄能类】或【守御类】：
  → 骗招失败，我本回合空过（能阶不变，无任何效果）

对方出【假动作】，我出【任一出刃类】：
  → 对方抢先命中，**对方获胜**
```

假动作是**零和的读心工具**：猜中赚一局，猜错浪费一回合。

### 4.6 爆能（违规判负）

- **神经能不足时打出需要更高能阶的招式** → 爆能，**立即淘汰**。
  （原版的"爆气"：气不够还硬放波，直接判死。）
- **抢拍 / 错拍**（未在倒数结束时出招） → 同爆能处理，
  且按世界观描述角色陷入短暂 Meltdown。

> 爆能规则是"节奏即代价"的落地。高手局里，
> 敢不敢在被压制时抢半拍出刀，本身就是一个决策。

## 5. 胜负与终局

### 5.1 1v1 终局条件

| 条件 | 结果 |
|---|---|
| 对方被淘汰 | 我获胜 |
| 双方能量同时归零且连续 2 回合无人被淘汰 | 判**平局**（双方都龟缩到死） |
| 达到第 **24** 回合 | 触发**终局共振**（见 §5.2） |

### 5.2 终局共振（24 回合制）

> 与已有游戏《神经交锋》保持一致的收束手法（该作"24 轮后得分更高者获胜"）。
> 第 24 回合后进入**终局共振**：双方能阶强制归零，
> 只能用 0 能招式对决（积能 / 刃幕 / 假动作），且**不能挥刀**。
> 于是最会攒的人会赢——但他必须在前 23 回合里活下来。

### 5.3 多人局（可选扩展）

原型天然支持多人（课间常见 4~8 人擂台）。本作多人版的收束规则：

```
- 任意一方出共振斩 → 除共振斩方外全部淘汰（原型原规则）
- 多人同威力平手 → 走【dadi 环】决胜（见 §6.3）
- 每回合至少有一人被淘汰 ⟹ 场上信息复杂度必然下降
  （淘汰者能阶清零）⟹ 天然的"熵减 → 熵增"节奏
```

## 6. 平衡设计：为什么这样定

### 6.1 三个缺陷，三个补丁

原型公认的三个结构性问题，以及本作的对策：

| 原型问题 | 社区解法 | 本作内建解法 |
|---|---|---|
| **无限防守导致平局** | 各种村规：防强上限、限定连续防次数、5 能清场 | `刃幕` 硬编码只有 2 级；强防必须花能（`侧滑`/`反射`/`深潜`）；+ §4.4 清场 |
| **积能正反馈太小**，攒半天只换来一次攻击的容错率提升 | 多种高级攻击 | `涌流`(+3) / `双生`(下回合+2) / `借势`(偷能) / 6 种出刃系 |
| **包装不参与结算**，招式只是一串词 | IP 联动村规（犀牛→恐龙克制环） | §6.3 `dadi 环` 直接写进规则 |

### 6.2 预期价值：为什么同时出招仍然有策略

石头剪刀布的三个动作期望价值都是 0（"没有价值的选择"）。
本作的做法是**让同一动作在不同局面下价值不同**——
策略深度来自**局面**，不来自选项数：

| 局面 | 蓄能 | 挥刀 | 守御 |
|---|---|---|---|
| 双方 0 能 | 必选 | 不可用 | 次优（能保命但对方必攒，下回合你就输） |
| 我 4 能 / 对方 2 能 | 弱（浪费一步） | **最强**（4 威力，无人能防） | 差（4 > 任何守御） |
| 我 4 能 / 对方 4 能 | 弱 | 平（对消） | 差（4 > 2 防御） |
| 我 2 能 / 对方 5 能 | 弱 | 必败 | 强（能拖到终局共振） |
| 我 5 能 / 对方 任意 | 弱 | **清场 / 收割** | 差 |

关键拐点：
- **能阶 5（共振斩）**：全局质变点，决胜期被强制压缩到极短。
- **能阶 4**：从"攻守兼备"滑向"只能攻"的临界。
- **能阶 ≥1 的守御**：从"保命"变成"用未来换现在"的交易。

### 6.3 `dadi 环` · 同威力决胜（多人 / 平手用）

当两名角色挥刀威力相同（原型里只是"互相抵消"，太弱），
本作引入一条**由世界观角色构成的克制环**——致敬原型"犀牛→恐龙"村规：

```
墨璇玥.iv → 米雅 → 咪呀 → Mia → 墨问 → Nihilib → 墨璇玥.iv
（胜者克制下一个，闭环）
```

- 环上**前者克后者**：环上相邻者，攻击方胜。
- 不相邻 → 双方无损。
- 1v1 局**默认不启用**（威力相同就抵消，保持规则简洁）；
  多人局或"共振斩同阶"时启用，作为打破对称的最终裁决。

> 选这 6 个名字是因为它们覆盖了世界观的三条主线：
> 墨璇玥.iv（大人国）、米雅（德澜思拓）、咪呀（M/I/A 家族）、
> 墨问 / Nihilib（哲华系科照真学院）。

## 7. 完整流程示例

```
开局：我 0 能 / 对方 0 能

R1  我【积能】  → 1 能
    对方【积能】→ 1 能           （0 能不能挥刀，双方只能攒）

R2  我【挥刀·轻斩】(1)  对方【积能】
    → 挥刀 vs 蓄能，我直接赢
    但如果对方 R2 出【刃幕】→ 1 ≤ 2，攻击被吸收，我白白把 1 能清零

R3  典型中局：我【反射】(2能→防4)  对方【重斩】(3能→威力4)
    → 4 ≤ 4，攻击被吸收并反弹 4 威力，我被淘汰

R4  我【贯穿】(4能→威力5)  对方【深潜】(防6)
    → 贯穿可无视格挡，但仍被深潜完整挡下

R5  决胜：我【共振斩】(5能)  对方【侧滑】(3能)
    → 共振斩无人可挡，对方淘汰
```
