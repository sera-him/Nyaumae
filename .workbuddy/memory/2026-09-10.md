## 经验

- 本机 Node fetch 会吃 `HTTP_PROXY` 环境变量 → 任何连本地服务的脚本都该用 `node:http` 或显式 NO_PROXY。
- `vite preview` 默认 `localhost` 解析到 `[::1]`（IPv6-only）→ 脚本里的 `127.0.0.1` 会连不上。
- fontsource `${weight}.css` 每块结构为 `/* family-subset-weight-style */ @font-face{...}`，且 src 同时列 woff2+woff（原脚本只拷 woff2 但没剥 woff URL）。
- 该站 PWA 注册入口在 ResilienceNotices.tsx（带 SKIP_WAITING 更新流程），不要再在 main.tsx 注册。
- 回归脚本复用模式：node workspace 下 shot-*.js + playwright-core + 系统 Edge，需 dangerouslyDisableSandbox。
