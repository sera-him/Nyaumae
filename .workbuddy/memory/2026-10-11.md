## 关键坑：desktop 构建脚本不跑词频语料生成
- `scripts/desktop-site-tool.mjs` 的 build 动作**不调用** `scripts/generate-frequency-corpus.mjs`（grep 无匹配），只有 `npm run build`（package.json）会先跑它。所以用桌面工具 build 后，新加进页面源码的文案不会自动进词频语料，必须**手动先跑一次 generate-frequency-corpus.mjs**，再 build + deploy，否则部署包里的词频是旧的。
- 本次因此多 build+deploy 一轮；已修正，线上 fullSearchIndex chunk 含 猫兔子/赛博朋克游侠/纺织/农民 等新表字段。
