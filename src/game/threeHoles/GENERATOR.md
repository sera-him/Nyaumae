# 狡兔三窟：自然团块题库与唯一解认证

网页端不再移动答案，也不再即时切割活动区。每道题的兔洞、活动区和
唯一解证书都由 `scripts/three_holes_unique_generator.py` 离线生成；
浏览器只会从同难度认证题目中随机抽题，并对整张题面做旋转或镜像。
旋转、镜像和区域编号置换都是双射，因此不会破坏唯一性。

## 题面规则

生成器为每个格子建立一个 CP-SAT 布尔变量，并严格约束：

1. 每行恰好 `k` 个兔洞；
2. 每列恰好 `k` 个兔洞；
3. 每个活动区恰好 `k` 个兔洞；
4. 任意八邻域内不能同时出现两个兔洞；
5. 若大盘仅靠区域仍无法在预算内收敛，可加入少量、在棋盘上明确显示且
   不可修改的“已知兔洞”或“已知排除”。

找到目标答案 `S` 后，认证模型会加入：

```text
sum(x[v] for v where S[v] = 1) <= n*k - 1
```

所有合法答案都有 `n*k` 个兔洞，所以这条约束只排除 `S`。固定题面线索也会
作为正式二值约束写入同一个认证模型：目标格固定为 `1`，排除格固定为 `0`，
两种线索都由网页明确呈现。生成器会从不同解池中优先选择一次能排除最多
不同解的线索，再逐个删除冗余线索。只有重新建立的屏蔽模型被 CP-SAT 严格
证明为 `INFEASIBLE`，题目才会进入题库；`UNKNOWN`、超时或仍存在第二解都
直接淘汰。

## 自然团块门槛

活动区由随机扩散种子形成的 Voronoi 团块开始，再通过保持目标答案的
局部边界调整消除不同解。每一次调整都必须继续满足四连通，并通过以下
拒绝指标：

- 区域包围盒不能极端细长；
- 区域不能是单列、单行或长走廊；
- 最长水平/垂直连续段不能占区域面积过高；
- 区域填充率和周长必须保持团块特征；
- 整盘水平、垂直边界数量不能严重偏向某一方向。

最后一项同时拒绝竖条盘面和横条盘面，所以运行时旋转后也不会变成满屏
竖条。

## 兔洞反规律门槛

目标答案由随机目标函数产生，但随机结果仍必须通过视觉规律检测：

- 拒绝高重合的小距离平移模板；
- 拒绝每隔两三行或两三列重复的周期；
- 拒绝过多相同的行/列兔洞模板；
- 拒绝过度集中在同一棋盘奇偶格；
- 拒绝几乎全部使用同一种兔洞间距。

这些指标只控制兔洞位置的视觉规律；行、列、区各 `k` 个以及不相邻规则
始终是硬约束。

## 复核

安装固定版本的 OR-Tools 后，可以重新证明整个题库：

```powershell
python -m pip install -r scripts/requirements-three-holes.txt
python scripts/three_holes_unique_generator.py `
  --verify src/game/threeHoles/puzzles.generated.json `
  --unique-time 360
```

复核会逐题检查尺寸、四连通、团块指标、兔洞反规律指标、行/列/区计数、
八邻域规则，并重新求解屏蔽模型。任何一项失败都会令命令失败。
